ICTR-LD 2026 certificate system

The problem

One Google Form link for a whole conference. Someone forwards it to a WhatsApp group, strangers fill it, people submit twice, and somebody ends up copying emails one by one to send certificates.

Handed over. Only real participants get through.

Drag to hand it over

DeterministicLiveForm and personal links are live.

What I built

  • Every participant gets a unique 8-character access code and a personal link with the code already filled in, emailed to them by name.
  • Each submission is checked the moment it lands: valid, duplicate, or not on the list. Forwarded links get caught.
  • The certificate step is built: verified responses fill the Slides template, which is exported to PDF, saved to Drive and set up to email.
  • Built to be safe to rerun. It skips anyone already handled and picks up after the Apps Script time limit. Nothing goes out until a person runs it.

Result

Used live for the ICTR-LD 2026 conference. The form and personal links are live, verified responses come back into one sheet, and only people with a valid code get through.
