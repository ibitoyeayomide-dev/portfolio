RIIC Certificate System

One workflow, two events, a personalised certificate for every participant.

Status
Used live for two events
For
RIIC, a university research and innovation office
Approach
Deterministic
Stack
n8n, Google Apps Script, Google Sheets, Google Forms, Google Slides, Google Drive, Gmail, Canva
  • 400+ participants
  • 2 events, 1 workflow
  • Valid, duplicate, invalid
  • Own error workflow
  1. Challenge
  2. Actions
  3. Results

ChallengeThe problem

For both the September capacity-building workshop and the ICTR-LD 2026 conference, the office needed to get a personalised certificate and message to every participant. Doing that by hand meant typing names into a template, exporting PDFs and emailing people one by one.

For the conference, a shared registration link also spread across WhatsApp groups, so the list itself had to be protected.

ActionsWhat I built

I built one certificate workflow and used it for both events. The Canva certificate template goes into Google Slides. n8n reads each name from a sheet, fills the certificate, saves the file to Drive, and emails the participant a personalised message with their certificate.

For ICTR-LD, I added a Google Apps Script verification layer across 5 Google services (Sheets, Forms, Slides, Drive, Gmail). It issued unique 8-character access codes to 2 participant groups, emailed each person a prefilled personal link, and sorted every submission into 3 states: valid, duplicate, or invalid. Only verified names went into the certificate run.

The workflow has its own error workflow, and it was built to be safe to repeat: it skipped anyone already sent.

ResultsWhere it stands

The same system was used for both events. Each participant received a personalised message and their certificate. It was used for over 400 people.

Duplicate and invalid conference submissions were stopped before they reached the certificate list.
